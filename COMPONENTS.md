# Components — plan and status

Source of truth for the shadcn/ui component plan and status.
Everything registered in the demo is always visible in `ComponentsRegistry.kt` — this file records the plan and the remaining work.
When adding or changing a component, update this file (step 5 of the cycle in AGENTS.md).

Other tasks (outside components) are tracked in [BACKLOG.md](BACKLOG.md).

Statuses: ✅ done (uikit + demo + registry) · 🚧 in progress · ⬜ planned · ❌ won't do
